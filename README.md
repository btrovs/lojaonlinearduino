# 🌳 Arduino Amazônia
Desenvolvimento de um protótipo de um site para a disciplina de Desenvolvimento Web - HTML, CSS, JavaScript e PHP. O site apresenta a proposta de um comércio eletrônico para a venda de projetos e objetos voltados 
para as áreas de sistemas embarcados, Iot (Internet das Coisas) e Robótica. Especializada na venda de componentes eletrônicos, placas de desenvolvimento.

## 🎯 Objetivo
O objetivo principal deste projeto é fornecer uma plataforma robusta e funcional para a venda de produtos eletrônicos, focando na experiência do usuário (UX) e na integridade do processo de compra.
código serve como exercício prático para aplicar:
- Gerenciamento de estado de carrinho de compras usando Sessões PHP;
- Comunicação assíncrona (AJAX) para atualizações do carrinho e cabeçalho sem recarregar a página;
- Padronização do design em todas as páginas e fluxos de compra (Catálogo, Carrinho e Finalização);
- Implementação de uma lógica de remoção unitária no carrinho.

## 💻 Tecnologias Utilizadas:
- PHP (Lógica de Backend e Gerenciamento de Sessão/Carrinho);
- HTML5 / CSS3 (Estrutura e Estilização);
- JavaScript (Lógica de frontend e eventos de interface, como Menu);
- AJAX (Fetch API/XHR) (Comunicação com salvar_carrinho.php e contador_carrinho.php).

## Antes de rodar o código, necessário instalar o PHP e um Servidor Web, por exemplo, Apache, Xammp.
